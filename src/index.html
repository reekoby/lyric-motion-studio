歌詞

歌声に合わせて自動配置は、音源の中央に定位したボーカルを解析し、各行の歌い出し・歌い終わりと単語のタイミングを推定します（すべてブラウザー内で処理）。イントロのリード楽器などを歌と取り違えたときは、その行を選んで歌い出しで ここから を押し、以降の行を歌声に合わせ直す を使うと後ろがそろいます。🔒の行は固定したまま合わせます。仮配置は文字数と音量からのおおまかな割り当てです。

クレジット

曲のジャンル・テーマ

テーマごとに、配色・書体・レイアウト・動き・エフェクトの候補を絞り込み、曲全体のトーン＆マナーをそろえます。音源を解析済みなら、盛り上がる区間ほど強めの演出を選びます。

動きの付け方

ジャンル・テーマで全体のトーンを決めたうえで、動きの激しさと付け方だけを調整できます。激しさは登場・退場・カメラ・トランジション・エフェクトの選び方と、動きの大きさ・速さにまとめて効きます。サビなど盛り上がる区間は、設定した激しさより少し強めになります。

曲構成（セクション）

イントロ／Aメロ／Bメロ／サビ などを指定すると、おまかせ演出がセクション単位でトンマナを切り替え、サビで最大の見せ場を作ります。タイムライン上段の帯でも編集できます（ダブルクリック：追加／クリック：種類切替／ドラッグ：移動／右クリック：削除）。推定は音量の変化からの目安です。

書体

書体はGoogle Fontsから読み込みます（オフライン時は端末の日本語フォントで代替）。「テーマに任せる」ではシーンごとにテーマの書体を使います。

字間・スペース

左へ動かすと詰まり、右へ動かすと広がります。フレーズごとの微調整は、右の詳細パネル「字間」「単語間」か、行を選んで [ / ]（字間・Shift で大きく）、Alt＋[ / ]（単語間）。

文字と動き

オンにすると、登場・退場の長さを 1/4〜3拍 のいちばん近い長さにそろえ、揺れや跳ねの周期も曲のテンポに合わせます。

背景モーション

不透明度・描画モードは「背景画像・動画」欄の「背景モーションの重ね方」と共通です。

歌詞のない区間（イントロ・間奏・アウトロ）

この区間だけの設定です。変えていない項目は「すべての区間」の設定に従います。タイムラインの斜線の帯をクリックしても選べます。

歌詞が表示されていない区間を自動で見つけ、テーマのトーンに合った背景モーションを小節ごとに切り替え、カメラのズームとビートの揺れを加えます（タイムラインでは斜線の帯で表示）。曲構成で「間奏」「イントロ」を指定すると表示ラベルにも反映されます。

GPUシェーダー（トンネル・万華鏡・レイマーチ空間・メッシュグラデ・ホログラム等）27種＋粒子・天気・水・炎・光・グリッチ・画面分割など66種、計93種類。「暗くする」で文字の読みやすさを調整できます。複数を重ねがけできます。行ごとの指定は右の詳細パネルから。

背景画像・動画

ここに画像・動画をドロップ（複数可・JPG / PNG / WebP / MP4 / WebM）

オンにすると、おまかせは画像を覆わない背景モーション（粒子・光・線など）だけを選び、画像がよく見える重ね方・なじませ・エフェクトに自動で調整します。文字が読みやすいよう影も付けます。

設定を初期状態にリセット

テーマ・配色・書体・レイアウト・モーション・エフェクト・背景モーション・歌詞のない区間・字間などの設定を初期状態に戻します。フレーズごとの個別設定も解除され、初期のテーマ（J-POP）で演出を付け直します。
