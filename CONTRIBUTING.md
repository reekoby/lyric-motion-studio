# Contributing / 開発への参加

Thanks for your interest! / ご関心ありがとうございます。

- Bugs & ideas: open an Issue with steps to reproduce, browser/OS, and (if possible) a small project file. / 不具合・要望は Issue へ（再現手順・ブラウザー/OS・可能ならプロジェクトファイル）。
- Pull requests: edit files in `src/` (not the built `index.html`), run `npm run build`, and describe what you changed. UI text is Japanese-source; add translations to `i18n/{en,es,it,ko}.json`. / 変更は `src/` に。画面の文言は日本語が原文で、翻訳は `i18n/` に追加します。
- Security issues: see [SECURITY.md](SECURITY.md) — please do not report them publicly. / セキュリティの問題は非公開で報告してください。
- By contributing you agree that your contribution is licensed under the MIT License. / 投稿いただいた変更は MIT ライセンスで公開されます。
